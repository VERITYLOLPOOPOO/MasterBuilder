# PouchiBuilder

PouchiBuilder is a responsive custom-PC building services site based in Marrakech. It includes service pricing, PCPartPicker intake, PC Creator, compatibility checks, location-based travel pricing, and build-request submission.

## Services

- PC Assembly — $50
- Wiring / cable management — $75
- Ship & Build — $150
- On-site travel tiers are calculated from the customer's detected location

## Brand

The site uses the simple Pouchi face as its main logo and favicon.

## Run locally

Open `index.html` in a browser. No build tools are required for the static front end.

## Main files

- `index.html` — PouchiBuilder site structure and content
- `style.css` — responsive visual design
- `script.js` — quote, compatibility and location logic
- `compatibility.css` — compatibility UI states
- `pouchi-logo.svg` — PouchiBuilder face logo
