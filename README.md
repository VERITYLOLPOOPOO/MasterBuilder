# MasterBuilder

MasterBuilder is a responsive PC-building services website with an interactive quote calculator.

## Services

- PC Assembly — $50
- Wiring / cable management — $75
- Ship & Build — $150

## Delivery pricing

- Within 100 miles — Free
- Within 500 miles — $5
- Another city — $50
- Another country — $100
- Another continent — $1,000

> Delivery availability and final pricing should be confirmed before parts are sent. Carrier charges, insurance, customs, taxes, and import fees may apply.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Files

- `index.html` — site structure and content
- `style.css` — responsive design
- `script.js` — instant quote calculator
